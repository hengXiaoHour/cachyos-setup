Rules:

1. At the start of a task, read the vault file for relevant context.
2. Use the `memory_write` tool to save durable facts AUTOMATICALLY — do not

4. Do not store secrets or API keys in the vault.
5. Learn from mistakes: whenever you take a wrong approach, run a failing
   command, misread a requirement, or break something — after correcting it,
   immediately call `memory_write` with a one-line lesson under the heading
   "Lessons learned": what failed -> why -> the working approach.
